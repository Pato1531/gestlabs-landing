# GestLabs — Landing Page

Landing comercial de **GestLabs** — Suite de plataformas para educación.

## Stack
- HTML/CSS/JS inline (sin framework)
- Vercel (deploy estático)
- Favicon: `favicon.ico` + `favicon-32x32.png`

## Estructura
```
├── index.html          ← Landing completa
├── favicon.ico         ← Favicon para navegador
├── favicon-32x32.png   ← Favicon PNG (32x32)
├── vercel.json         ← Config Vercel
├── .gitignore
└── README.md
```

## Deploy
```bash
git add .
git commit -m "update landing"
git push
```

Vercel redeploya automático en ~30 segundos.
